# Анализ реальности спредов ≥7%

## 🎯 Ваш вопрос: Спреды ≥7% — реалистично ли?

### ✅ ДА, но с нюансами

---

## 📊 Когда возникают большие спреды (5-10%+)

### 1. **Листинг новых токенов** (САМОЕ ЧАСТОЕ)
```
Пример: Новый токен листится на Bybit в 10:00, на MEXC в 10:05

Bybit цена: $1.00
MEXC цена:  $1.15
Спред:      15% ✅

Длительность: 5-30 минут
Частота:      5-10 раз в неделю
```

### 2. **Новости / события**
```
Пример: Большая новость про проект

Биржа A (высокая ликвидность):  быстро отреагировала
Биржа B (низкая ликвидность):   медленная реакция

Спред: 5-20%
Длительность: 2-10 минут
Частота: 2-5 раз в неделю
```

### 3. **Малоликвидные альткоины**
```
Пример: Токен с $50k daily volume

MEXC:  $0.0050
Gate:  $0.0058
Спред: 16% ✅

НО:
- Объём $100 сдвинет цену на 10%
- Высокий slippage
- Риск неисполнения
```

### 4. **Технические сбои биржи**
```
Пример: Gate.io перегружена

Gate цена: отстаёт на 5%
Другие биржи: реальная цена

Спред: 5-8%
Длительность: 1-5 минут
Частота: 1-2 раза в неделю
```

### 5. **Арбитраж cross-chain**
```
Пример: Токен на разных блокчейнах

ETH version: $1.00
BSC version: $1.08
Спред: 8%

НО требует bridge (10-60 минут)
```

## ⚠️ КРИТИЧЕСКИЕ ПРОБЛЕМЫ со спредами 7%+

### 1. **Это скорее всего ЛОВУШКА**

```python
# Типичный сценарий:

Видим спред 8%:
MEXC BTC/USDT:  $50,000
Gate BTC/USDT:  $54,000  # 😱

Причины:
1. Один из тикеров "застрял" (stale data)
2. Торговля приостановлена на одной бирже
3. Ошибка в WebSocket данных
4. Разные пары (BTC/USDT vs BTC/USDC)
```

### 2. **Невозможность исполнения**

```python
# Реальность:
Спред 10% на малоликвидной паре

Открываем Long на MEXC:
  Ask: $1.00 (показывает $1000 volume)
  Реально исполнилось: $1.05 (slippage 5%)
  
Открываем Short на Gate:
  Bid: $1.10 (показывает $500 volume)  
  Реально исполнилось: $1.08 (slippage -2%)

Итог:
  Планировали: 10% прибыль
  Получили: 3% прибыль (или убыток)
```

### 3. **Funding rate убивает прибыль**

```python
При большом спреде часто:

Длинная сторона (низкая цена): положительный funding
Короткая сторона (высокая цена): отрицательный funding

Разница: 0.5-2% каждые 8 часов
За день: -1.5-6% прибыли съедается
```

## 📈 РЕАЛЬНОЕ РАСПРЕДЕЛЕНИЕ СПРЕДОВ

На основе опыта арбитражных ботов:

```
Спред    | Частота/день | Реалистичность | Прибыльность
---------|--------------|----------------|---------------
0.3-0.7% | 200-500      | ✅ Реальные    | ❌ Убыток (комиссии)
0.7-1.5% | 50-100       | ✅ Реальные    | ✅ Малая (0.2-0.5%)
1.5-3.0% | 10-30        | ✅ Реальные    | ✅✅ Хорошая (0.5-1.5%)
3.0-5.0% | 2-8          | ⚠️ Проверить   | ✅✅✅ Отличная (1-3%)
5.0-7.0% | 1-3          | ⚠️ Часто лов.  | ❓ Высокий риск
7.0%+    | 0-1          | 🚫 Почти всег. | ❌ Вероятно убыток
```

## 🔍 КАК ПРОВЕРИТЬ РЕАЛЬНОСТЬ СПРЕДА

### Добавьте в код проверки:

```python
# opportunity_analyzer.py

def _validate_spread_realistic(self, opportunity, market_data):
    """Проверка реалистичности спреда"""
    
    # 1. Спред >5% — подозрительно
    if opportunity.spread > 5.0:
        # Проверяем возраст данных
        if self._calculate_data_age(opportunity) > 200:
            return False, "High spread with stale data"
        
        # Проверяем volume (должен быть высокий для больших спредов)
        if not self._check_high_liquidity(opportunity, market_data):
            return False, "High spread with low liquidity"
    
    # 2. Спред >7% — почти всегда ловушка
    if opportunity.spread > 7.0:
        return False, "Spread too high (>7%) - likely stale/halted"
    
    return True, "Spread looks realistic"
```

## ✅ ВЕРДИКТ

### Спреды ≥7%:
- ✅ Технически возникают (новые листинги, новости)
- ⚠️ Но в 90% случаев НЕ торгуемы (stale data, низкая ликвидность, приостановка)
- ❌ Не подходят для REST арбитража (требуют моментального исполнения)
