## 📋 Чеклист перед запуском

### 1. Проверка API ключей
```bash
# Убедитесь что .env заполнен правильно
cat .env | grep API_KEY
```

### 2. Проверка на testnet (рекомендуется)
Большинство бирж предоставляют testnet:
- Bybit: https://testnet.bybit.com
- Gate.io: https://fx-test.gateio.ws
- MEXC: проверьте документацию

**Замените в .env:**
```
BYBIT_API_KEY=<testnet_key>
BYBIT_API_SECRET=<testnet_secret>
```

### 3. Начальный баланс
Рекомендуем начать с **$100-500** для тестирования

### 4. Параметры риск-менеджмента

В `config.py`:
```python
# Консервативные настройки для начала
POSITION_SIZE_FRACTION = 0.05  # 5% от баланса (вместо 10%)
MAX_OPEN_POSITIONS = 1         # Максимум 1 позиция
MAX_LEVERAGE = 5               # Плечо 5x (вместо 10x)

# Порог для открытия
OPEN_THRESHOLD = 0.8  # Amplitude: 0.8%+ (безопаснее чем 0.5%)
OPEN_THRESHOLD = 7.0  # Collapse: 7.0%+ (безопаснее чем 5%)
```

## 🔴 Активация Live торговли

### В `main.py`:
```python
# Измените эту строку:
USE_LIVE_TRADING = True  # ← Было False
```

### Или через командную строку:
```python
# Создайте live_trading.py
from main import ArbitrageSystem, STRATEGY
import asyncio

async def main():
    system = ArbitrageSystem(
        use_api_keys=True,      # ✅ Используем API ключи
        initial_balance=500,    # Ваш начальный баланс
        strategy=STRATEGY,
        demo_mode=False         # ✅ Реальная торговля
    )
    
    await system.initialize()
    await system.run(duration_seconds=None)  # Бесконечно

if __name__ == "__main__":
    asyncio.run(main())
```

Запуск:
```bash
python live_trading.py
```

## 🛡️ Защита и мониторинг

### 1. Установите лимиты на биржах
- **IP Whitelist** — только ваш IP
- **Withdrawal disabled** — отключите вывод средств
- **Trading only** — только торговля
- **Max order size** — ограничьте размер ордера

### 2. Мониторинг
```bash
# Отслеживайте логи
tail -f arbitrage.log  # Если включите file logging
```

### 3. Stop conditions
Система остановится автоматически при:
- Критической ошибке API
- Отрицательном балансе
- Превышении max позиций

### 4. Ручная остановка
```
Ctrl+C — корректная остановка
```
Система закроет все открытые позиции перед выходом.

## ⚠️ Риски

### 1. Slippage
Реальное исполнение может быть хуже из-за:
- Недостаточной ликвидности
- Задержки сети
- Изменения цены между анализом и исполнением

**Решение:** Начните с малых объёмов

### 2. API Errors
Биржи могут:
- Отклонить ордер
- Временно недоступны
- Rate limit превышен

**Решение:** Система автоматически откатывает неудачные ордера

### 3. Funding Rate
При длительном удержании (>8ч) начисляется funding

**Решение:** Collapse стратегия закрывает позиции до 1 часа

## 🚨 Действия при проблемах

### Система не находит возможности
```python
# Уменьшите порог в config.py
OPEN_THRESHOLD = 0.5  # Amplitude
OPEN_THRESHOLD = 4.0  # Collapse
```

### Позиции не открываются
- Проверьте баланс на биржах
- Убедитесь что API ключи верны
- Проверьте IP whitelist
- Посмотрите логи ошибок

### PnL отрицательный
- Проверьте комиссии бирж
- Убедитесь что slippage не слишком большой
- Увеличьте OPEN_THRESHOLD

### Ошибки API
- Проверьте rate limits
- Убедитесь что ключи не истекли
- Проверьте permissions (trading enabled)
