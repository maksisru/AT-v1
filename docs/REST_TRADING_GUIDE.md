# REST API Арбитраж — Реальность и Оптимизация

## 🎯 Можно ли торговать арбитраж через REST?

**Да, но с правильными ожиданиями и настройками.**

---

## ⚡ REST vs WebSocket

### REST API
- **Latency:** 100-300ms на 2 параллельных ордера
- **Преимущества:** Простота, надёжность, не требует постоянного соединения
- **Недостатки:** Медленнее чем WebSocket для исполнения

### WebSocket (только для данных)
- **Latency получения данных:** 10-50ms
- **Используем для:** Реалтайм мониторинг спредов
- **НЕ используем для:** Размещения ордеров (биржи не поддерживают WS trading или это сложнее)

## 📊 Реалистичные параметры для REST

### Текущие настройки (оптимизированы)

```python
# Открытие
OPEN_THRESHOLD = 1.0           # Минимум 1% gross spread
MIN_NET_EDGE = 0.3             # Минимум 0.3% чистой прибыли
MAX_DATA_AGE_MS = 500          # Данные не старше 500ms

# Издержки
TAKER_FEE_PCT = 0.05           # 0.05% × 4 = 0.2%
SLIPPAGE_PCT = 0.05            # 0.05% × 4 = 0.2%
REST_EXECUTION_BUFFER = 0.1    # 0.1% буфер на REST задержку

# Закрытие (REST Optimized Strategy)
TAKE_PROFIT = 0.4%             # Фиксированный TP
STOP_LOSS = 0.3%               # Фиксированный SL
MAX_HOLD_TIME = 180 сек        # 3 минуты максимум
TRAILING_STOP = 0.5%           # Активация после 0.5% прибыли
```

## 🎯 Улучшения в коде

### 1. OpportunityAnalyzer
✅ Ужесточены пороги:
- MIN_GROSS_SPREAD: 0.35% → **1.0%**
- MIN_NET_EDGE: 0.15% → **0.3%**
- MAX_DATA_AGE: 1000ms → **500ms**
- SLIPPAGE: 0.02% → **0.05%**

✅ Добавлен REST_EXECUTION_BUFFER: 0.1%

### 2. RestOptimizedStrategy (новая)
✅ Фиксированные уровни:
- Take Profit: **0.4%**
- Stop Loss: **0.3%**
- Trailing Stop: активируется после **0.5%**
- Max Hold Time: **180 секунд**

✅ Преимущества над Amplitude:
- Не зависит от исторической волатильности
- Быстрое исполнение (3 минуты vs 5 минут)
- Простая логика — меньше ошибок

### 3. RiskManager
✅ Добавлена проверка ликвидности:
```python
# Требуем минимум 3x от размера позиции в volume
if long_data.volume < position_size * 3:
    reject()
```

**REST арбитраж работает при:**
1. ✅ Спредах 1%+ (после фильтров → 0.3-0.6% net)
