# 🎯 Momentum Reversal Strategy

## Концепция

Новая стратегия, которая **ловит момент разворота импульса спреда**.

### Отличие от других стратегий:

| Стратегия | Спред | Сигнал закрытия | Частота |
|-----------|-------|-----------------|---------|
| **Amplitude** | 0.5-1% | 70% от макс амплитуды | 50-150/день |
| **Collapse** | 5%+ | Спред < 0.1% | 1-5/день |
| **Momentum** | 1-3% | Разворот тренда спреда | 10-30/день |

---

## Как работает

### Импульс (Momentum)
Скорость изменения спреда:
```
T0: Спред 2.0%
T1: Спред 1.5%  →  Изменение: -0.5% (спред снижается быстро)
T2: Спред 1.2%  →  Изменение: -0.3% (снижается медленнее)
T3: Спред 1.3%  →  Изменение: +0.1% (РАЗВОРОТ!) ← Закрываем!
```

### Разворот (Reversal)
Когда спред меняет направление движения:
- Был отрицательный импульс (спред снижался) → стал положительный
- Или наоборот

---

## Параметры

```python
window_size = 10              # История последних 10 точек
reversal_threshold = 0.05     # Минимальное изменение для разворота (0.05%)
min_profit_pct = 0.3          # Минимальная прибыль 0.3%
max_hold_time_sec = 600       # Максимум 10 минут
```

---

## Условия закрытия

### 1. Разворот импульса + прибыль
```
Импульс развернулся И PnL > 0.3%
→ Закрываем, спред может вырасти обратно
```

### 2. Спред движется против нас
```
Спред вырос на >0.5% от входа И PnL отрицательный
→ Закрываем, убытки будут расти
```

### 3. Целевая прибыль
```
PnL > 50% от входного спреда
→ Фиксируем прибыль
```

### 4. Timeout
```
Удерживаем >10 минут
→ Принудительно закрываем
```

## Преимущества

✅ **Ловит оптимальный момент** — закрывает на пике прибыли  
✅ **Средние спреды** — чаще чем collapse, реже чем amplitude  
✅ **Адаптивная** — подстраивается под волатильность  
✅ **Защита от убытков** — детектирует неблагоприятное движение

## Недостатки

❌ Требует больше данных (10+ тиков)  
❌ Может закрыть раньше максимума  
❌ Сложнее оптимизировать параметры

## Когда использовать

**Выбирайте Momentum если:**
- ✅ Средние спреды 1-3% (чаще чем collapse 5%+)
- ✅ Хотите автоматически ловить развороты
- ✅ Готовы держать 1-10 минут
- ✅ Рынок волатильный

**Не используйте если:**
- ❌ Спреды очень маленькие (<0.5%) — используйте amplitude
- ❌ Спреды очень большие (>5%) — используйте collapse
- ❌ Нужна простая стратегия

```python

```

В `main.py` добавить:
```python
from strategies import MomentumReversalStrategy

# В initialize():
elif self.strategy_name == 'momentum':
    self.close_strategy = MomentumReversalStrategy(
        window_size=10,
        reversal_threshold=0.05,
        min_profit_pct=0.3,
        max_hold_time_sec=600
    )
```
