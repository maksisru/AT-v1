# Сравнение стратегий

## 1. Амплитудная стратегия (Amplitude)

### Концепция
Ловим **микроколебания** цен внутри спреда, многократно открываем и закрываем позиции.

### Параметры
```python
STRATEGY = 'amplitude'
OPEN_THRESHOLD = 0.3%      # Малый спред
CLOSE: 70% от макс амплитуды
Hold time: 5-30 секунд
```

### Когда использовать
- Высокая ликвидность на биржах
- Частые маленькие спреды (0.3-1%)
- Низкие комиссии (maker 0.02%)
- Высокоскоростное исполнение

### Преимущества
✅ Много сделок в день (50-150)
✅ Быстрая фиксация прибыли
✅ Низкий риск на сделку
✅ Не зависит от направления рынка

### Недостатки
❌ Высокие требования к latency
❌ Комиссии съедают прибыль при малых спредах
❌ Требует точной оценки амплитуды

### Типичный результат
```
Сделок в день: 50-150
Прибыль на сделку: 0.2-0.5 USD
Дневная прибыль: 10-75 USD (1-7.5%)
Win rate: 70-80%
```

---

## 2. Схлопывание спреда (Collapse)

### Концепция
Ждём **полного схлопывания** большого спреда, фиксируем крупную прибыль за одну сделку.

### Параметры
```python
STRATEGY = 'collapse'
OPEN_THRESHOLD = 5.0%      # Большой спред
CLOSE: спред < 0.1% ИЛИ прибыль > 70% от входа
Hold time: 5-60 минут
```

### Когда использовать
- Низкая ликвидность (emerging монеты)
- Редкие большие спреды (5-15%)
- Новости/события создают дисбаланс
- Не критична скорость исполнения

### Преимущества
✅ Большая прибыль на сделку (50-500 USD)
✅ Комиссии незначительны относительно прибыли
✅ Меньше стресса от мониторинга
✅ Проще реализовать

### Недостатки
❌ Редкие возможности (1-5 в день)
❌ Долгое удержание позиции (риск funding)
❌ Риск незакрытия (спред не схлопывается)
❌ Требует больше капитала

### Типичный результат
```
Сделок в день: 1-5
Прибыль на сделку: 50-500 USD
Дневная прибыль: 50-500 USD (5-50%)
Win rate: 60-70%
```

## Рекомендации по выбору

### Выбирайте Amplitude если:
- ✅ У вас быстрый VPS близко к биржам
- ✅ Maker комиссии <0.02%
- ✅ Хотите стабильный поток малых прибылей
- ✅ Готовы оптимизировать параметры
- ✅ Работаете с топ-10 монетами (BTC, ETH, etc)

### Выбирайте Collapse если:
- ✅ Работаете с emerging altcoins
- ✅ Не критична скорость (обычный VPS)
- ✅ Готовы ждать редких возможностей
- ✅ Хотите большую прибыль за сделку
- ✅ Начинаете с малого капитала

## Гибридный подход

Можно запустить **две системы параллельно**:

```python
# Система 1: Amplitude на BTC/ETH (топ ликвидность)
system_amplitude = ArbitrageSystem(strategy='amplitude')

# Система 2: Collapse на altcoins (большие спреды)
system_collapse = ArbitrageSystem(strategy='collapse')
```

### Распределение капитала
- 70% → Amplitude (стабильная прибыль)
- 30% → Collapse (высокодоходные сделки)

---

## Настройка для вашего случая

### Если капитал < 500 USD
→ **Collapse** (меньше сделок, больше прибыль на сделку)

### Если капитал 500-5000 USD
→ **Гибрид** (60% amplitude, 40% collapse)

### Если капитал > 5000 USD
→ **Amplitude** (масштабируемость через объём сделок)

---

## Как переключить стратегию

### В config.py:
```python
# Амплитудная
STRATEGY = 'amplitude'
OPEN_THRESHOLD = 0.3

# Схлопывание
STRATEGY = 'collapse'
OPEN_THRESHOLD = 5.0
```

Система автоматически выберет правильные параметры для выбранной стратегии.
