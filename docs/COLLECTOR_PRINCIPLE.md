# 📊 Принцип работы сборщика данных

## 🎯 Ключевое отличие от торговой системы

### Торговая система (main.py):
```
WebSocket → Найти спреды → Применить фильтры стратегии → Открыть позицию
                              ↓
                         ✅ OPEN_THRESHOLD ≥ 1.0%
                         ✅ MIN_NET_EDGE ≥ 0.3%
                         ✅ MAX_DATA_AGE ≤ 500ms
                         ✅ ...много других фильтров
```

### Сборщик данных (data_collector.py):
```
WebSocket → Найти спреды ≥0.3% → Записать ВСЁ в CSV
                                   ↓
                              🚫 НЕТ фильтров
                              📊 Только сбор данных
```

---

## 🔬 Что собирается:

### Условие: `gross_spread ≥ 0.3%`

Если спред найден → записываем ВСЁ:

```python
# RAW данные (как есть):
- timestamp
- symbol
- exchange_long, exchange_short
- price_long, price_short
- bid_long, ask_long
- bid_short, ask_short
- volume_long, volume_short
- funding_rate_long, funding_rate_short

# Вычисленные метрики:
- gross_spread_pct
- net_edge_pct (с учётом fees, slippage, bid-ask)
- bid_ask_spread_long_pct
- bid_ask_spread_short_pct
- data_age_ms
- funding_diff

# Справочная информация:
- would_be_approved (одобрено с отключенными фильтрами = всегда True)
- reject_reason (пусто, т.к. фильтры отключены)
```

---

## ⚙️ Конфигурация сборщика

```python
# data_collector.py
collector_config = {
    'MIN_GROSS_SPREAD': 0.3,       # Собираем от 0.3%
    'MIN_NET_EDGE': -10.0,         # НЕТ фильтрации по net edge
    'MAX_GROSS_SPREAD': 100.0,     # Собираем любые спреды
    'MAX_BID_ASK_SPREAD_PER_LEG': 10.0,  # НЕТ фильтрации bid-ask
    'MAX_DATA_AGE_MS': 10000       # НЕТ фильтрации по возрасту
}

# Результат: собирается ВСЁ что ≥0.3%
```

## 📈 Workflow анализа

```
1. Сборщик (2-3 дня):
   → Собирает ВСЁ (спреды ≥0.3%)
   → CSV с 10,000+ записями

2. Анализатор:
   → Читает CSV
   → Группирует по диапазонам
   → Вычисляет статистику
   → Моделирует разные стратегии
   
3. Рекомендации:
   → Консервативная (1.5%+, net edge 0.5%)
   → Стандартная (0.8%+, net edge 0.3%)
   → Агрессивная (0.5%+, net edge 0.15%)
   
4. Выбор стратегии:
   → Обновляете config.py
   → Запускаете main.py
```

---

## 💡 Почему так?

### ❌ Если бы сборщик применял фильтры:
```
Фильтр: MIN_NET_EDGE = 0.3%

Результат:
- Спреды 0.3-0.7% не попадут (net edge отрицательный)
- Не увидите сколько их было
- Не сможете выбрать micro-spread стратегию
```

### ✅ С отключенными фильтрами:
```
Собрано всё ≥0.3%

Анализатор показывает:
- 0.3-0.5%: 500 записей, net edge -0.1% (не торгуемо)
- 0.5-0.7%: 400 записей, net edge 0.05% (микро-стратегия?)
- 0.7-1.0%: 600 записей, net edge 0.25% (агрессивная стратегия)
- 1.0-2.0%: 800 записей, net edge 0.6% (стандартная стратегия)
- 2.0%+:    200 записей, net edge 1.5% (консервативная стратегия)

→ Видите ВСЁ и выбираете оптимальное
```

## 🎯 Итого

**Сборщик = чистый регистратор данных**
- 🚫 Никаких стратегических решений
- 📊 Только факты: цены, спреды, volume
- 💾 Всё в CSV для анализа

**Анализатор = мозг выбора стратегии**
- 📈 Группирует данные
- 🧮 Вычисляет метрики
- 🎯 Рекомендует стратегии

**Вы = принимаете решение**
- 💰 Выбираете risk/reward баланс
- ⚙️ Настраиваете config.py
- 🚀 Запускаете торговлю
