# Настройка Telegram уведомлений

## Шаг 1: Создание бота

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду: `/newbot`
3. Введите имя бота: `My Arbitrage Bot`
4. Введите username: `my_arbitrage_bot` (должен заканчиваться на `bot`)
5. Получите **токен**: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

## Шаг 2: Получение Chat ID

### Вариант 1: Через @userinfobot
1. Найдите в Telegram: **@userinfobot**
2. Отправьте `/start`
3. Получите ваш **Chat ID**: `123456789`

### Вариант 2: Через группу
1. Создайте группу в Telegram
2. Добавьте бота в группу
3. Откройте: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":-1001234567890}`

## Шаг 3: Настройка в config.py

```python
# config.py
TELEGRAM_BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
TELEGRAM_CHAT_ID = "123456789"  # или "-1001234567890" для группы
```

## Шаг 4: Тест

Запустите систему:
```bash
python main.py
```

Вы должны получить сообщение в Telegram:
```
🚀 Система запущена

💰 Баланс: 1000 USD
📊 Стратегия: COLLAPSE
🏦 Биржи: mexc, gate, bybit, asterdex
🕐 Время: 2026-06-04 11:22:00
```

## Типы уведомлений

### 1. Система
- ✅ Запуск системы
- ✅ Остановка системы
- ⚠️ Предупреждения о рисках
- ❌ Критические ошибки

### 2. Торговля
- 🔍 Найдена возможность
- ✅ Позиция открыта
- ✅ Позиция закрыта (прибыль)
- ❌ Позиция закрыта (убыток)

### 3. Статистика
- 📊 Дневная статистика (каждые 24ч)
- 📈 Еженедельный отчёт
- 💰 Отчёт по PnL

## Отключение Telegram

Если не хотите уведомления, оставьте в config.py:
```python
TELEGRAM_BOT_TOKEN = None
TELEGRAM_CHAT_ID = None
```

Система будет работать без уведомлений.

## Безопасность

⚠️ **Не публикуйте токен бота и chat_id в публичных репозиториях!**

Используйте переменные окружения:
```bash
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
```

И в config.py:
```python
import os
TELEGRAM_BOT_TOKEN = os.getenv('TELEGRAM_BOT_TOKEN')
TELEGRAM_CHAT_ID = os.getenv('TELEGRAM_CHAT_ID')
```
