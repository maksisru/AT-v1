# Амплитудная стратегия — Быстрый старт

## Концепция в одном предложении
**Ловим микроколебания цен между биржами и фиксируем прибыль на пиках амплитуды**

---

## Параметры (config.py)

```python
# Баланс и позиция
Баланс:          1000 USD
Размер позиции:  100 USD (1/10 баланса)
Макс позиций:    3 одновременно
Плечо:           10x (реальный объём = 1000 USD)

# Открытие
Минимальный спред:  0.3%
Максимальный спред: 2.0%

# Закрытие
Целевая амплитуда:  70% от средней максимальной
Минимальная прибыль: 5 USD
Stop-loss:          -10 USD (2x минимальной)
Timeout:            300 сек (5 минут)
```

---

## Пример работы

### Шаг 1: Обнаружен спред
```
Bybit:  BTC = 65,100 (ask)
Gate:   BTC = 65,200 (bid)
Спред:  +0.15% ✅ → ОТКРЫВАЕМ
```

### Шаг 2: Открытие позиции
```
LONG  @ Bybit  65,100 USD  (размер: 100 USD × 10 leverage = 1000 USD)
SHORT @ Gate   65,200 USD  (размер: 100 USD × 10 leverage = 1000 USD)

Entry spread: +100 USD
```

### Шаг 3: Мониторинг амплитуды
```
Через 2 секунды:
  Bybit:  65,110 (+10 USD) → PnL: +0.015% × 1000 = +0.15 USD
  Gate:   65,193 (-7 USD)  → PnL: +0.011% × 1000 = +0.11 USD
  
Текущая амплитуда: +0.26 USD

Средняя макс (90-й перцентиль): 0.35 USD
Порог закрытия (70%): 0.245 USD

0.26 > 0.245 → ✅ ЗАКРЫВАЕМ
```

### Шаг 4: Закрытие и переоткрытие
```
Фиксация: +0.26 USD прибыль

Если спред всё ещё >0.3% → Сразу ПЕРЕОТКРЫВАЕМ
Цикл повторяется...
```

## Защитные механизмы

| Условие | Действие | Причина |
|---------|----------|---------|
| Амплитуда ≥ порог | ✅ Закрыть | Достигли цели |
| Амплитуда < -10 USD | ❌ Закрыть | Stop-loss |
| Время > 5 минут | ⏱️ Закрыть | Timeout |
| Спред развернулся | 🔄 Закрыть | Защита от убытка |

## Риски

### 1. Комиссии
```
Maker:  0.02% × 4 (вход/выход на 2 биржах) = 0.08%
Taker:  0.05% × 4 = 0.20%

На позицию 100 USD (с leverage 10x = 1000 USD):
  Maker: 0.08% × 1000 = 0.8 USD
  Taker: 0.20% × 1000 = 2.0 USD

✅ Решение: Целевая прибыль 5 USD > 2 USD комиссии
```

### 2. Slippage
```
Рыночный ордер может исполниться на 0.01-0.03% хуже

✅ Решение: Проверяем ликвидность стакана перед входом
```

### 3. Несинхронное исполнение
```
Если одна биржа исполнила ордер, а вторая нет:
  → Направленный риск (незахеджированная позиция)

✅ Решение: 
  - Параллельное открытие (asyncio.gather)
  - Откат при неудаче
  - Timeout 5 секунд на открытие
```
