# 🔬 Сборщик данных для анализа стратегии

## Зачем это нужно?

**Сборщик данных НЕ применяет стратегии — он просто собирает ВСЁ.**

Когда спред ≥0.3%, сборщик записывает:
- ✅ Все цены (bid, ask на обеих биржах)
- ✅ Спреды (gross spread, bid-ask)
- ✅ Funding rates
- ✅ Volume (ликвидность)
- ✅ Timestamps (для анализа latency)
- ✅ Расчётный net edge

**Фильтры стратегий ОТКЛЮЧЕНЫ** — собирается всё подряд.

Потом анализатор предложит оптимальные стратегии на основе ВАШИХ данных.

---

## 🚀 Быстрый старт

### 1. Запуск сборщика данных (3 суток)

```bash
python data_collector.py
```

Или указать свою длительность в часах:
```bash
python data_collector.py 48  # 2 суток
python data_collector.py 168 # Неделя
```

### 2. Ждём 2-3 суток

Компьютер должен работать. Сборщик:
- ✅ НЕ открывает позиции
- ✅ Только собирает статистику
- ✅ Показывает прогресс каждые 5 минут
- ✅ Можно остановить Ctrl+C в любой момент

### 3. Анализ собранных данных

```bash
python data_analyzer.py data_collection/spreads_YYYYMMDD_HHMMSS.csv
```

Анализатор покажет:
- 📊 Распределение спредов
- ✅ Сколько одобрено/отклонено
- 💰 Средний net edge
- 📡 Качество данных
- 🎯 **РЕКОМЕНДАЦИИ ПО НАСТРОЙКАМ**

## 💡 Советы

### 1. Запускайте в разное время
- Активность меняется (день/ночь, будни/выходные)
- Лучше собрать данные за неделю

### 2. Проверяйте прогресс
- Каждые 5 минут выводится статистика
- Убедитесь что возможности находятся

### 3. Если мало данных
```python
# В data_collector.py можно снизить порог:
system.arbitrage_engine.find_opportunities_parallel(
    market_data,
    0.3,  # Было 0.5 → попробуйте 0.3
    50
)
```

---

## 🔍 Что делать если...

### Нет возможностей / очень мало
- Проверьте WebSocket подключения
- Снизьте порог в data_collector.py (строка 103)
- Возможно низкая активность на рынке

### Слишком много данных (>100k записей)
- Это нормально!
- CSV файл может быть 10-50 MB
- Анализатор справится

### Компьютер завис / отключился
- Не страшно! Данные сохраняются постоянно
- Можете проанализировать то что успело собраться
