# Оптимизация через Maker ордера

## 🎯 Идея

Вместо Taker ордеров (по рынку) размещать Limit ордера на лучшие цены.

## 💰 Преимущества

### Экономия на комиссиях:
```
Taker fee: 0.05% × 4 = 0.20%
Maker fee: 0.01% × 4 = 0.04% (иногда 0% или даже rebate)
───────────────────────────
Экономия: 0.16% на каждой сделке!
```

### При спреде 1.0%:
```
С Taker:
Gross: 1.0% - Fees: 0.2% = Net: 0.8% (до slippage)

С Maker:
Gross: 1.0% - Fees: 0.04% = Net: 0.96% (без slippage)
```

## ⚠️ Недостатки

1. **Риск неисполнения** — ордер может не исполниться
2. **Задержка** — ждём пока кто-то возьмёт наш ордер
3. **Спред может уйти** — пока ждём, арбитраж исчезнет

## 🎯 Гибридная стратегия

```python
# Для маленьких спредов (1-2%) — только Taker (гарантия исполнения)
if spread < 2.0:
    use_taker_orders()

# Для больших спредов (2%+) — пробуем Maker с fallback на Taker
elif spread >= 2.0:
    try_maker_with_timeout(timeout=5sec)
    if not_filled:
        cancel_and_use_taker()
```

## 📊 Реальность

Для арбитража **Taker ордера предпочтительнее**:
- Гарантированное исполнение
- Моментальная синхронность обеих позиций
- Спред может исчезнуть за секунды

**Maker имеет смысл только для спредов 3%+** где есть время подождать.
