## Если что-то не работает

### Проблема: Ошибки импорта
```bash
pip install -r requirements.txt --upgrade
```

### Проблема: WebSocket не подключаются
- Проверьте интернет
- Проверьте firewall
- Попробуйте перезапустить

### Проблема: Не находит возможности
- Уменьшите OPEN_THRESHOLD в config.py
- Подождите 5-10 минут (рынок волатилен)
- Проверьте что WebSocket получают данные

### Проблема: Медленная работа
- Проверьте performance_config.py
- Уменьшите SYMBOLS_PER_EXCHANGE
- Проверьте загрузку CPU
